## 방식: 상품별 AE 사전 렌더링 (2026-09-27 사용자 결정)

상품 PNG(`REPLACE TRANSPARENT PRODUCT PNG`, 2000² 안에 자동 맞춤)와 상품명(`EDIT_02_PRIZE_NAME`) 위로 WIN 글자·노이즈 광선·엠블럼·하단 패널이 계속 움직여, 앱에서 상품만 얹으면 겹침 순서가 달라진다. 그래서 상품마다 AE에서 영상을 뽑는다. 현장 변수와 기기 부하가 가장 적은 방식이다.

## 앱 동작 (swc-apac-v10)

상품별 영상은 관리자 IP·상품 탭에서 등록한다. 앱에 번들된 당첨 영상은 없다. 등급과 관계없이 모든 상품 행에 두 영상 칸이 있다.

| 영상 칸 | 쓰임 |
| --- | --- |
| 특별 영상 (선택) | 당첨 시 가장 먼저 전체 화면 시네마틱. 상급 피규어의 연출용이다. 소리는 업로드 영상의 오디오를 Web Audio로 디코딩해 재생한다(iPad 제스처 밖 재생 대비). 디코딩에 실패하면 영상 자체 소리를 쓴다 |
| 상품 영상 (선택) | 이어서 전체 화면 당첨 화면(OAP v5 사전 렌더). 없으면 기존 금색 당첨 카드(상급·일반) 또는 참가상 카드 |

상품 등급(드롭다운):

| 등급 | 추첨 규칙 |
| --- | --- |
| 상급 | 확률 사용 시 상급 확률(%)로 상급 여부를 먼저 정한다. 시간 제한·쿨다운도 상급 당첨만 센다 |
| 일반 | 상급이 아닌 추첨에서 참가상과 함께 재고 비율로 뽑는다 |
| 참가상 | 일반과 같다. 영상이 없으면 결과 화면은 "아쉽네요!" 참가상 카드 |

- 당첨 효과음 시점(v21): 상품 영상이 있으면 영상 시계 1.4초(AE `PRIZE REVEAL` 레이어 시작 = 상품 등장)에 재생한다. 영상이 멈춰도 2.4초 뒤에는 재생한다. 카드 결과는 즉시 재생한다.
- 표시 등급(v21): 관리자 상품 행의 등급이 A~H 드롭다운이다(기존 자유 입력값은 "기존값"으로 유지). 추첨 분류(상급/일반/참가상)와 별개다. A/B 축하 화면과 당첨 화면 등급 배지는 시안 확인 후 적용한다.
- 당첨 효과음(v13): 상급 = 관리자 `스페셜`, 일반 = `일반당첨`, 참가상 = `참가상`(v13 추가 칸). 업로드가 없으면 각각 기본 합성음(참가상은 낮아지는 두 음)을 쓴다.
- 특별 영상은 끝까지 재생한다. 멈춤 감시 타이머는 영상 길이가 확인되면(loadedmetadata, playing) 남은 재생 시간 + 3초로 다시 맞춘다(v12).
- 클릭 팝업 영상 기능은 삭제했다(v10). 참가상 카드 이미지를 눌러도 아무 일이 없다.
- 흐름: 오픈 종료 → 흰 화면 → (특별 영상) → 0.4초 페이드 → (상품 영상 또는 카드).
  - 영상은 추첨 확정 즉시 IndexedDB에서 읽기 시작한다.
  - 드래그 완료처럼 여유가 없으면 첫 영상이 준비될 때까지 흰 화면을 유지한다(최대 2.5초).
- 등록 규격: 특별·상품 영상은 iPad Pro 3세대 H.264 한도(레벨 4.2, 프레임당 8704 매크로블록) 안이어야 등록된다. 2048×2732 마스터는 거부한다. 1024×1366을 권장한다.
- 이전 데이터:
  - v6까지 당첨 상품의 `상품 영상`을 시네마틱으로 썼으므로, 로드 시 상급 상품의 `상품 영상`을 `특별 영상`으로 옮긴다.
  - `kind`가 없는 상품은 `tier`로 판단한다(high → 상급, 그 외 → 참가상).
- 백업: `.kuji` 백업·복원과 영상 제외 복원이 `specialVideoKey`, `winVideoKey`를 보존한다.
- 스태프 확인: 상품 영상 오른쪽 아래에 `SHOW THIS SCREEN TO STAFF / No. 일련번호 · 시각`이 2.4초에 나타난다.
- 복귀:
  - 관리자 기본 설정 `결과 복귀(초)`(최소 3초, 기본 7초)가 상품 영상·카드·참가상 결과에 모두 적용된다.
  - 상품 영상은 등장 애니메이션이 끝난 뒤(2.5초, 영상 시계) 탭하면 즉시 메인으로 간다.
  - 메인 복귀 때 화면 전환 영상이 재생된다.
