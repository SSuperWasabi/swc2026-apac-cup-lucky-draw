# 소환서 선택 화면 v8 — 앱 적용 명세

원본: `swc2026_CHOOSE_YOUR_SCROLL_iPad_INTRO_LOOP_v8_260923.aep` / 컴포지션 `21-1_CHOOSE_YOUR_SCROLL_INTRO_THEN_LOOP_V8` (2048×2732, 30fps).
값은 AE 사본에서 스크립트로 직접 추출했다(2026-09-27, AE 26.5). 영상 판독으로 추정한 값이 아니다.

- [layout.json](layout.json): 요소별 최종 위치·크기(좌상단 기준, master / css1024 / % 세 단위)와 겹침 순서
- [motion.json](motion.json): 요소별 등장 시작·길이·이징·시작/끝 값

두 JSON은 `scripts/ae/build-choose-v8-spec.cjs`로 추출본에서 다시 생성한다. 손으로 고치지 않는다.

## 구성 원칙

조작하는 요소만 앱 요소로 분리하고, 나머지는 영상에 굽는다(현장 변수·부하 최소화).

| 구분 | 내용 |
| --- | --- |
| 배경 영상(굽기) | APAC 금색 배경, 상단 명암 그라데이션, Com2uS Store 로고, CHOOSE YOUR / SCROLL / SWC2026 APAC LUCKY DRAW 제목과 그 페이드인 |
| 앱 요소(14개) | 소환서 카드 12장, RANDOM 버튼, SELECT YOUR SCROLL 버튼 |

배경은 AE에서 원본 영상의 재생 시점을 `3 − cos(πt/2)`로 왕복시키는 4초 주기 표현식이라 웹 재현 대상이 아니다.

## 재생 구조

1. `choose-bg-intro.mp4`(0–2초, 60프레임)를 한 번 재생
2. 이어서 `choose-bg-loop.mp4`(2–6초, 120프레임)를 반복

두 파일 모두 1024×1366, H.264 High 4.1, 30fps, 무음, 키프레임 간격 30. 반복 경계와 intro→loop 경계는 일반 프레임 간 차이와 같은 수준으로 이어진다.

## 등장 애니메이션

모두 **선형(linear)**. 시간 기준은 intro 영상의 첫 표시 프레임이다.

| 요소 | 시작(초) | 길이(초) | 변화 |
| --- | --- | --- | --- |
| RANDOM | 0.300 | 0.45 | 불투명도 0→1 |
| 카드 01 → 12 | 0.380부터 0.055 간격 (12번 0.985) | 0.45 | 불투명도 0→1, 아래 40 master px(=CSS 20px)에서 제자리 |
| SELECT YOUR SCROLL | 0.900 | 0.45 | 불투명도 0→1 |

모든 앱 요소 등장은 **1.435초**에 끝난다. AE 마커: 0초 INTRO, 2초 LOOP START, 6초 두 번째 배경 주기.

입력 허용 시점은 AE에 정의돼 있지 않다. 앱 적용 시 결정한다(후보: 등장 완료 1.435초, 또는 loop 시작 2초).

## 에셋

`resource/oap/ae-work/render/choose-v8/` (Git 제외, 앱 적용 시 최적화본만 `app/assets`로 승격)

- `web/choose-bg-intro.mp4`, `web/choose-bg-loop.mp4`: 앱 요소를 끈 원본 컴포지션 렌더(알파 TIFF 시퀀스 180장)에서 인코딩

## 검증 결과

배경 프레임(t=3) 위에 14개 PNG를 명세 좌표로 합성해 AE 원본 프레임과 비교했다.

- 앱 요소가 없는 영역(헤더, 카드 사이, 하단): 완전 일치(PSNR ∞)
- 요소 영역: 차이는 가장자리 1px 안쪽에만 있다. ffmpeg가 소수 좌표(125.02, 562.4, 2352.5)를 정수로 내리고 16bit 알파를 8bit로 합성해 생긴 차이이며, 면 내부는 일치한다. 브라우저는 소수 좌표를 그대로 쓸 수 있다.

## 앱 구현 (swc-apac-v2)

- `app/choose-screen.js`: intro 첫 표시 프레임(`requestVideoFrameCallback`)에서 등장 CSS를 시작한다. 700ms 안에 영상이 시작되지 않으면 등장만 먼저 진행한다. intro가 끝나면 마지막 프레임을 유지한 채 loop 첫 프레임이 표시된 뒤 intro를 숨긴다. 화면을 떠날 때 두 영상을 정지하고 0초로 되돌린다.
- 입력은 마지막 카드 등장이 끝나는 1.435초부터 받는다. 뒤로 버튼은 항상 받는다.
- 카드 그리드는 한 번만 만든다. 다시 그리면 등장 애니메이션이 재시작된다.
- 위치는 CSS `calc(100% * master px / 2048)` 형태의 원본 픽셀 비율로 넣는다. 반올림한 %는 Chrome에서 1 기기픽셀 어긋났다.
- 원본 스크립트: `scripts/ae/` (추출 `extract-aep.jsx`, 소스 재연결 `relink-footage.jsx`, 에셋 출력 `export-choose-v8.jsx`)

### 검증 (Chrome, `scripts/test-choose-browser.cjs`)

- 등장 시작 시 intro 위치 0.007~0.045초, 입력 허용 1.44초
- 14개 요소 상자가 layout.json과 무대 대비 0.05% 이내
- DPR 2(2048×2732) 화면 캡처를 AE 원본 t=3초와 요소별 비교: 모두 PSNR 30dB 초과(최저 31.95dB, ±1 기기픽셀 허용)
